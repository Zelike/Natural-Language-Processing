# 实验3：统计语言模型

## 使用方法

1. 完整解压本文件夹，保留 Notebook 与 `data/` 的相对位置。
2. 在已配置的 Python 环境中打开 `NLP实验3_统计语言模型_实验指导.ipynb`。
3. 从 Notebook 所在目录启动，先检查数据路径，再完成任务一和任务二；也可自行编写 Python 脚本。
4. “实践区”用于编写代码，“分析区”和“记录区”用于整理结果。运行现有单元格不等于完成实验。
5. 使用 `dev.csv` 选择模型设置，固定配置后运行测试，再读取 `test.csv` 中的 `answer` 列直接验证准确率。

## 数据文件

| 文件 | 内容 | 数量 | 编码 |
|---|---|---:|---|
| `data/train.txt` | 空格分词、一行一句，无标题 | 72句 | UTF-8 |
| `data/dev.csv` | 验证题，含 `answer` | 12题 | UTF-8 with BOM |
| `data/test.csv` | 测试题，含 `answer` | 12题 | UTF-8 with BOM |
| `data/challenge.csv` | 挑战题，含 `analysis_focus`，无单一答案 | 6题 | UTF-8 with BOM |

Python 读取 CSV 时建议指定 `encoding="utf-8-sig"`，以自动去除 BOM；训练文本使用 `encoding="utf-8"`。

原始训练语料为72句、358词次、141种普通词语；加入 `</s>` 和 `<unk>` 后，预测词表大小为143。`<s>` 仅作为上下文，`____` 不加入词表。本数据为实验自编语料，不是公开基准或真实用户日志。

CSV 每行一题：`id` 为唯一编号；`sentence` 含一个独立的 `____` 词元；`option_A`—`option_D` 为四个单词候选；`answer` 为验证题和测试题参考选项；`analysis_focus` 为挑战题分析提示。

## 准确率验证

按 `id` 将预测结果与 `answer` 对齐，以“预测选项等于参考选项”的题数除以题目总数得到准确率。测试集共12题，另外报告最高分并列题数。

参考答案仅用于评价，不作为模型输入或候选排序依据。通过验证集选定参数后，不依据测试答案返回调参。挑战题和自编题不并入普通测试准确率。
